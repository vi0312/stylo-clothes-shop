# Seed assets

Placeholder catalog images used by `prisma/seed.ts`. `seed` copies them into
`$UPLOAD_DIR/products/` and reuses them across products, so the demo never downloads
anything at runtime.

| File | Used by |
|---|---|
| `catalog-01.png` … `catalog-06.png` | 19 seeded products; `Áo khoác dù` intentionally has no image |

The six files are flat-colour placeholders with a simple shirt silhouette and the text
"STYLO / ĐỒ ÁN DEMO". They were drawn for this project with Pillow on 2026-11-07 and are
released under CC0 1.0. They are not photographs of real products, so no product,
photographer or stock-site licence applies.
